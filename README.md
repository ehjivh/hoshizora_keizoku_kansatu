# 星空の明るさ調査 GeoJSON変換プログラム

環境省が実施する「星空の明るさ調査」のCSVデータを、WebGIS等での可視化に資するGeoJSON形式に変換・集計するPHPプログラムです。

## 📋 機能

- **自動ファイル検出**: `result_YYYY_S.csv` および `result_YYYY_W.csv` ファイルを自動走査
- **文字エンコーディング対応**: SJIS/UTF-8を自動判別・変換
- **複数行フィールド対応**: ヘッダに改行を含むCSV形式に対応
- **データ分類**: 継続観察登録地点と一般地点を自動分類
- **時系列集計**: 同一地点・同一調査時期のデータを平均化
- **GeoJSON出力**: RFC 7946準拠の2種類のGeoJSONファイルを生成

## 💻 動作環境

| 要件                   | バージョン                             |
| ---------------------- | -------------------------------------- |
| PHP                    | 8.1以上                                |
| 必要な拡張             | mbstring（文字エンコーディング変換用） |
| 入力ファイル文字コード | UTF-8 または SJIS                      |
| 出力ファイル文字コード | UTF-8                                  |

## 📂 入力データ仕様

### ファイル形式
- **パターン**: `result_[0-9]{4}_[SW].csv`
  - `YYYY`: 西暦4桁（例：2026）
  - `S`: 夏季（Summer）
  - `W`: 冬季（Winter）

### CSVカラム
プログラムは以下のカラムを認識します（表記揺れに対応）：

| 必須 | カラム名         | 説明                                      |
| ---- | ---------------- | ----------------------------------------- |
| ○    | No               | 観測番号                                  |
| ○    | 都道府県         | 都道府県名                                |
| ○    | 市区町村         | 市区町村名                                |
|      | 撮影場所         | 撮影場所名                                |
|      | 撮影日時         | 撮影日時（YYYY/M/D HH:MM:SS形式）         |
| ○    | 緯度             | 観測地点の緯度（小数点表記）              |
| ○    | 経度             | 観測地点の経度（小数点表記）              |
| ○    | 夜空の明るさ     | 夜空の明るさ（等級/□°）                   |
| ○    | ばらつき         | 観測のばらつき                            |
|      | 周辺状況         | 周辺の状況説明                            |
|      | 備考             | 備考                                      |
|      | 継続観察登録地点 | ◎ または 〇：継続観察登録地点の場合に記入 |

## 📊 出力形式

プログラムは以下の2つのGeoJSONファイルを生成します。

### 1. `continuous_points.geojson`

継続観察登録地点用。同一地点の時系列データを集約し、調査時期ごとに平均値を算出します。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [142.483, 44.374]
      },
      "properties": {
        "都道府県": "北海道",
        "市区町村": "名寄市",
        "撮影場所": "なよろ市立天文台",
        "時系列データ": [
          {
            "調査時期": "2026_W",
            "観測回数": 3,
            "夜空の明るさ_平均": 19.45,
            "ばらつき_平均": 0.13
          },
          {
            "調査時期": "2025_S",
            "観測回数": 5,
            "夜空の明るさ_平均": 19.42,
            "ばらつき_平均": 0.12
          }
        ]
      }
    }
  ]
}
```

### 2. `general_points.geojson`

一般地点用。継続観察登録地点以外の観測を1フィーチャとしてフラットに記録します。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [140.753, 41.783]
      },
      "properties": {
        "調査時期": "2026_W",
        "都道府県": "北海道",
        "市区町村": "小樽市",
        "撮影場所": null,
        "撮影日時": "2026/8/15 21:00",
        "夜空の明るさ": 20.39,
        "ばらつき": 0.14
      }
    }
  ]
}
```

## 🚀 使用方法

### 基本的な実行方法

```bash
php converter.php
```

プログラムはスクリプトと同じディレクトリ内の全てのCSVファイルを自動的に検出し処理します。

### 処理フロー

1. **ファイル走査**: `result_*.csv` ファイルリストを自動取得
2. **CSV読み込み**: 各ファイルを読み込み、エンコーディングを変換
3. **ヘッダ正規化**: カラム名の表記揺れを統一
4. **データ分類**: 継続観察フラグに基づいてデータを分類
5. **集計処理**: 継続観察地点の同一時期データを平均化
6. **GeoJSON出力**: 2つのGeoJSONファイルを生成

## 📝 処理ルール

### 地点キーの生成
- 緯度・経度を小数第3位で丸めて地点を識別
- 同一地点の判定に使用

### 継続観察地点の判定
- 「継続観察登録地点」カラムの値が「◎」または「〇」の場合、継続観察地点として分類

### 時系列データの集計
- 同一地点・同一調査時期に複数の観測データがある場合
  - 「夜空の明るさ」の算術平均を算出（小数第2位で丸め）
  - 「ばらつき」の算術平均を算出（小数第2位で丸め）
  - 観測回数をカウント

### 座標系
- GeoJSONは [経度, 緯度] の順序（RFC 7946準拠）
- WGS84座標系（EPSG:4326）

## 🔧 クラス・メソッド仕様

### StarrySkyDataConverter クラス

#### プロパティ
```php
private string $inputDir           // 入力ディレクトリパス
private string $outputDir          // 出力ディレクトリパス
private array $rawContinuousData   // 継続観察地点の生データ
```

#### メソッド

| メソッド                                                  | 説明                                                           |
| --------------------------------------------------------- | -------------------------------------------------------------- |
| `__construct(string $inputDir, string $outputDir = null)` | コンストラクタ。出力ディレクトリ省略時は入力ディレクトリと同じ |
| `execute(): void`                                         | メイン処理。全体の制御を行う                                   |
| `scanCsvFiles(): array`                                   | ファイルシステムを走査してCSVファイルを検出                    |
| `processFile(string $filePath, string $period): void`     | CSVファイルを読み込んでデータを分類                            |
| `normalizeHeader(array $header): array`                   | ヘッダ行を正規化                                               |
| `detectEncoding(string $contents): string`                | 文字エンコーディングを判別                                     |
| `generateLocationKey(float $lat, float $lon): string`     | 地点キーを生成                                                 |
| `isContinuousPoint(string $value): bool`                  | 継続観察登録地点かどうかを判定                                 |
| `aggregateContinuousData(): array`                        | 継続観察地点データを集計・集約                                 |
| `exportGeoJson(string $filename, array $features): void`  | GeoJSONをファイルに出力                                        |

## ⚠️ 注意点

1. **文字エンコーディング**: SJIS/UTF-8以外の文字コードには対応していません
2. **複数行フィールド**: CSVの複数行フィールド（ダブルクォートで囲まれた改行）に対応しています
3. **出力上書き**: 既存のGeoJSONファイルは上書きされます
4. **メモリ使用**: 大規模なCSVファイルの場合、メモリ使用量が増加する可能性があります

## 🐛 トラブルシューティング

### ファイルが見つからない
- `result_` で始まるCSVファイルがディレクトリに存在することを確認してください
- ファイル名が `result_YYYY_S.csv` または `result_YYYY_W.csv` パターンに合致していることを確認してください

### 出力ファイルが空または不完全
- CSVファイルの文字エンコーディングを確認してください（SJIS/UTF-8のみ対応）
- ヘッダ行および必須カラムが正しく含まれていることを確認してください

### PHPエラー
- PHP 8.1以上をインストールしていることを確認してください
- `mbstring` 拡張がインストール・有効化されていることを確認してください
