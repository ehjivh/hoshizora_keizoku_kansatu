# 星空の明るさ調査 GeoJSON変換プログラム

環境省が実施する「星空の明るさ調査」のデータ（CSV形式）を、GISや分析用途での分析・可視化に活用しやすいGeoJSON形式へ変換・集計するPHPプログラムです。

## 主な機能と特徴

- **自動ファイル処理**: `csv/` フォルダ内の `result_YYYY_S.csv` および `result_YYYY_W.csv` などを一括処理。
- **文字エンコーディングの自動補正**: 日本語Windows環境に多いShift-JISやBOM付きUTF-8を自動判定し、内部でUTF-8に統一。
- **日時の国際標準化 (ISO 8601)**: 様々な表記の「撮影日時」をISO 8601形式（例: `2018-08-02T21:01:00+09:00`）へ統一パース。
- **継続観察地点の時系列集計**: 継続的に観測が行われている地点を特定し、調査時期ごとの平均値を算出して時系列データとして出力。
- **研究用データのクレンジング**: 「備考」欄に記載のある異常値・天候不良等の観測データを集計から自動除外。

## 動作環境

| 要件             | バージョン・指定                         |
| ---------------- | ---------------------------------------- |
| PHP              | 8.1以上                                  |
| 必須拡張         | mbstring (文字エンコーディング変換用)    |
| 入力ディレクトリ | スクリプトと同階層の `csv/` フォルダ     |
| 出力ディレクトリ | スクリプトと同階層の `geojson/` フォルダ |

## データ仕様と処理ルール

本プログラムは、以下の仕様に基づきデータを処理・変換します。

### 1. 座標と地点の識別
- **座標系**: WGS84（EPSG:4326）、GeoJSONのRFC 7946仕様に準拠し `[経度, 緯度]` の順序で格納。
- **同一地点の判定 (継続観察地点)**:
  「継続観察登録地点」カラムが `○` または `〇` であるデータを対象とします。同一地点かどうかの判定は、**緯度・経度をそれぞれ小数第3位（約100m精度）で丸めた値** をキーとして行われます。

### 2. 日時データの標準化 (ISO 8601)
「撮影日時」カラムの文字列はすべて `YYYY-MM-DDThh:mm:ss+09:00` 形式へ統一されます。
- **年情報の欠落補完**: 一部のデータ（例：2018年夏期の `8月2日 9:01 PM` など）に年が含まれていない場合、ファイル名から抽出した調査時期（例: `2018_S`）から西暦を補完してパースします。
- **12時間表記の補正**: `AM/PM` 表記を24時間表記に正規化します。

### 3. データクレンジングと集計（継続観察地点）
`continuous_points.geojson` への集計時、以下のルールが適用されます。
- **備考欄による除外**: 天候不良などイレギュラーな条件を排除するため、**「備考」カラムに何らかの文字列が含まれる観測データは、平均値の算出および観測回数のカウントから完全に除外**されます。
- **平均値の算出**: 同一地点・同一調査時期における有効データについて、「夜空の明るさ」と「ばらつき」の算術平均を**小数第2位で丸めて**算出します。
- **完全除外**: 全調査時期において有効データが1件も存在しなくなった地点は、GeoJSONの出力対象から除外されます。

## 出力ファイル形式

プログラムを実行すると、`geojson/` フォルダ内に以下のファイルが生成されます。

### 1. 個別ファイルのGeoJSON (`result_YYYY_S.geojson` など)
入力された各CSVファイルと1対1で対応するファイルです。すべての観測データがポイントフィーチャとしてフラットに記録されます。

### 2. `all_points.geojson`
すべてのCSVファイルのデータを1つのFeatureCollectionに統合したファイルです。
各Featureの `properties` には、どの時期のデータかを示す `調査時期` カラムが自動追加されます。

### 3. `continuous_points.geojson`
継続観察登録地点のデータを集約したファイルです。各地点は1つのポイントフィーチャとなり、プロパティ内に調査時期ごとの集計結果が配列として格納されます。

```json
{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [140.7525, 41.78277778]
  },
  "properties": {
    "都道府県": "北海道",
    "市区町村": "函館市",
    "撮影場所": "函館山",
    "時系列データ": [
      {
        "調査時期": "2019_W",
        "観測回数": 5,
        "夜空の明るさ_平均": 18.23,
        "ばらつき_平均": 0.15
      },
      {
        "調査時期": "2018_S",
        "観測回数": 3,
        "夜空の明るさ_平均": 18.10,
        "ばらつき_平均": 0.20
      }
    ]
  }
}
```

## 使用方法

### 準備
1. 本プログラム (`csv_to_geojson.php`) と同じ階層に `csv` という名前のフォルダを作成します。
2. `csv` フォルダ内に、環境省から提供されたCSVファイル（`result_YYYY_S.csv` など）を配置します。

### 実行
ターミナル（コマンドプロンプト等）で以下のコマンドを実行します。

```bash
php csv_to_geojson.php
```

### 実行結果
処理が完了すると、自動的に `geojson` フォルダが作成され、変換・集計されたデータが出力されます。

```
Processing result_2018_S.csv...
Saved 214 features to result_2018_S.geojson
...
Generating all_points.geojson with 8014 features...
Saved combined features to all_points.geojson
Generating continuous_points.geojson with 725 features...
Saved continuous points to continuous_points.geojson
Done.
```

## クラス設計 (`CsvToGeoJsonConverter`)
プログラムはオブジェクト指向でリファクタリングされており、メンテナンス性に優れています。
- `execute()`: 全体のファイル走査と処理フロー制御
- `processFile()`: 1CSVファイルごとのパース・正規化・生成
- `formatToIso8601()`: 日時文字列のISO 8601パース処理
- `collectContinuousData()`: 継続観察地点の識別と集約
- `exportContinuousGeoJson()`: 備考判定を含むデータクレンジングと平均値集計処理
